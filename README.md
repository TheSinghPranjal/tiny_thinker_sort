# SortJoy

Joyful sorting games for kids ages **1–7** — sparkles, smiles, and zero scolding.

Companion-style Flutter app in the TinyThink design philosophy, focused on sorting, matching, and categorization.

## Run

```bash
flutter pub get
flutter run
```

## What’s included (vertical slice)

1. **App shell** — onboarding age select, home games grid, rewards HUD, parent gate + Parent Zone  
2. **Shared sorting engine** — drag → drop zones → gentle guidance (no fail state) → timer → celebration → rewards  
3. **Fruit & Vegetable Sort** — Tiny Learners (3–5) farm scene with continuous floating produce  

## Age worlds

- Little Explorers (1–2)
- Tiny Learners (3–5)
- Smart Sorters (6–7)

Full catalog is listed on Home; unimplemented games show **Soon**. Free tier: **5 plays per game per day** (toggle Premium in Parent Zone for unlimited).

## Brand promise

**SortJoy helps kids learn by sorting — with sparkles, smiles, and zero scolding.**
